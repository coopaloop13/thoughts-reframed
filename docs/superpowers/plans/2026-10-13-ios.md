# Reframed Thoughts iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A SwiftUI iPhone app that signs in with Apple, enrolls the user's voice, records a negative thought, streams the backend pipeline's progress over a GraphQL subscription, plays the reframed affirmation in the user's own voice, and lists past sessions.

**Architecture:** Apollo iOS 2.x (SPM) with codegen from `backend/schema.graphql`; HTTP for queries/mutations/uploads and WebSocket (graphql-transport-ws) for the subscription via `SplitNetworkTransport`. Views talk to an `API` struct of async closures (one live implementation over Apollo, stubbed in tests) so ViewModels are unit-tested without the network. An `@Observable AppState` owns the token (Keychain) and routes between Sign-in, Enroll, and the main tabs. Project is generated from `project.yml` with xcodegen so the `.xcodeproj` is reproducible.

**Tech Stack:** Swift 6 (Xcode 27), SwiftUI, iOS 17.0+, AuthenticationServices, AVFoundation, Apollo iOS 2.4.x (`Apollo`, `ApolloWebSocket`, `ApolloAPI`), `apollo-ios-cli` codegen, Swift Testing (`import Testing`), xcodegen 2.46.

**Spec:** `docs/superpowers/specs/2026-10-13-reframed-thoughts-design.md`. Backend contract: `backend/schema.graphql` (committed, exported by `npm run schema:export`).

## Global Constraints

- iOS 17.0 deployment target; Swift 6 language mode with strict concurrency; SwiftUI only (no UIKit view controllers except what AuthenticationServices requires).
- Bundle id `com.coopertech.reframedthoughts` (must equal the backend's `APPLE_BUNDLE_ID`). Test bundle `com.coopertech.reframedthoughtsTests`.
- TDD: every ViewModel/model/service change starts with a failing Swift Testing test in `ReframedThoughtsTests`. Run with `xcodebuild test -project ios/ReframedThoughts.xcodeproj -scheme ReframedThoughts -destination 'platform=iOS Simulator,name=iPhone 16' -quiet`.
- The GraphQL schema is the backend's `schema.graphql`; never hand-edit generated code under `ios/ReframedThoughts/Generated/`. Regenerate with `ios/Tools/apollo-ios-cli generate` after any backend schema change.
- Subscription semantics (backend ruling R10): `sessionUpdated(id)` emits the current row first, then live updates, and completes after `COMPLETED` or `FAILED`. The app must not assume it sees `TRANSCRIBING` first.
- Errors from the backend carry `extensions.code` ∈ `UNAUTHENTICATED`, `INVALID_APPLE_TOKEN`, `VOICE_NOT_ENROLLED`, `NOT_FOUND`; everything else is `Unexpected error.`. `UNAUTHENTICATED` anywhere ⇒ sign out.
- Uploads use the GraphQL multipart spec: Apollo `GraphQLFile(fieldName:)` where `fieldName` equals the GraphQL variable name (`sample`, `recording`); the `File` scalar maps to `String` in codegen and the operation is called with the field name as the value.
- Recordings: AAC in `.m4a`, 44.1 kHz mono (reuse the old app's settings). Enrollment sample must be at least 8 seconds.
- Ponytail mode: no protocols with one implementation (the `API` struct-of-closures is the single seam), no third-party packages beyond Apollo.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Xcode license is accepted on this machine; `git` and `xcodebuild` work normally.

## Review Focus

1. Backend returns `UNAUTHENTICATED` on any operation (expired token, deleted user) → app clears the token and shows Sign-in, not an error toast. (Test in Task 5.)
2. User kills the app mid-pipeline and reopens → History shows the session with its latest status; tapping a non-terminal one resubscribes and the snapshot event brings it current. (Test in Task 7.)
3. Microphone permission denied → Record and Enroll screens show a clear message with a Settings deep link instead of a silent failure. (Test in Task 6.)
4. Enrollment recording shorter than 8 s → rejected locally before upload. (Test in Task 6.)
5. Subscription ends with `FAILED` → Processing screen shows the error and a Retry that returns to Record, never a spinner forever; the WebSocket connection is torn down. (Test in Task 7.)

```swift
import Foundation

struct AppConfig {
    let base: URL
    var httpURL: URL { base.appending(path: "graphql") }
    var wsURL: URL {
        var c = URLComponents(url: httpURL, resolvingAgainstBaseURL: false)!
        c.scheme = c.scheme == "https" ? "wss" : "ws"
        return c.url!
    }

    static func baseURL(env: [String: String] = ProcessInfo.processInfo.environment,
                        infoPlist: (String) -> String? = { Bundle.main.object(forInfoDictionaryKey: $0) as? String }) -> URL {
        if let s = env["API_BASE_URL"], !s.isEmpty, let u = URL(string: s) { return u }
        if let s = infoPlist("APIBaseURL"), let u = URL(string: s) { return u }
        return URL(string: "http://localhost:8080")!
    }
    static func devJWT(env: [String: String] = ProcessInfo.processInfo.environment) -> String? {
        guard let t = env["DEV_JWT"], !t.isEmpty else { return nil }
        return t
    }
    static let current = AppConfig(base: baseURL())
}
```

`ios/ReframedThoughts/Network/TokenStore.swift`:

```swift
import Foundation
import Security

struct TokenStore {
    var service = "com.coopertech.reframedthoughts"
    private let account = "jwt"
    private var query: [String: Any] { [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service, kSecAttrAccount as String: account] }

    func read() -> String? {
        var q = query; q[kSecReturnData as String] = true; q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: AnyObject?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess, let d = out as? Data else { return nil }
        return String(data: d, encoding: .utf8)
    }
    func write(_ token: String) throws {
        clear()
        var q = query; q[kSecValueData as String] = Data(token.utf8); q[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly
        let status = SecItemAdd(q as CFDictionary, nil)
        guard status == errSecSuccess else { throw NSError(domain: NSOSStatusErrorDomain, code: Int(status)) }
    }
    func clear() { SecItemDelete(query as CFDictionary) }
}
```

```swift
import Foundation

struct User: Equatable { let id: String; let hasVoice: Bool }

enum SessionStatus: String, Equatable, Sendable {
    case uploaded = "UPLOADED", transcribing = "TRANSCRIBING", reframing = "REFRAMING",
         synthesizing = "SYNTHESIZING", completed = "COMPLETED", failed = "FAILED"
    var isTerminal: Bool { self == .completed || self == .failed }
}

struct Session: Identifiable, Equatable, Sendable {
    let id: String
    let status: SessionStatus
    let transcript: String?
    let reframedText: String?
```

```swift
                return try unwrap(r).sessions.map { Session($0.fragments.sessionFields) }
            },

                let r = try await client.fetch(query: GQL.SessionQuery(id: id), cachePolicy: .networkOnly)
                return try unwrap(r).session.map { Session($0.fragments.sessionFields) }
            },
            watchSession: { id in
                AsyncThrowingStream { continuation in
                    let task = Task {
                        do {
                            for try await r in client.subscribe(subscription: GQL.SessionUpdatedSubscription(id: id)) {
                                let s = Session(try unwrap(r).sessionUpdated.fragments.sessionFields)
                                continuation.yield(s)
                                if s.status.isTerminal { break }
                            }
                            continuation.finish()
                        } catch { continuation.finish(throwing: mapError(error)) }
                    }
                    continuation.onTermination = { _ in task.cancel() }
                }
            },
            deleteAccount: { _ = try unwrap(try await client.perform(mutation: GQL.DeleteAccountMutation())) }
        )
    }

    /// Throws APIError for GraphQL errors; returns data otherwise.
    private static func unwrap<D>(_ response: GraphQLResponse<D>) throws -> D where D: RootSelectionSet {
        if let e = response.errors?.first {
            throw APIError.from(code: e.extensions?["code"] as? String, message: e.message ?? "Unexpected error.")
        }
        guard let data = response.data else { throw APIError.server("Empty response") }
        return data
    }

        if let e = error as? APIError { return e }
        return APIError.transport(error.localizedDescription)
```

```swift
import Foundation
import Observation

@MainActor @Observable
final class AppState {
    enum Route: Equatable { case loading, signedOut, enroll, main }
    private(set) var route: Route = .loading
    private(set) var user: User?
    private(set) var api: API
    var lastError: String?

    private let tokenStore: TokenStore
    private let makeAPI: (String?) -> API
    private let devJWT: String?

    init(tokenStore: TokenStore = TokenStore(), makeAPI: @escaping (String?) -> API, devJWT: String? = AppConfig.devJWT()) {
        self.tokenStore = tokenStore; self.makeAPI = makeAPI; self.devJWT = devJWT
        self.api = makeAPI(tokenStore.read() ?? devJWT)
    }

    func start() async {
        guard let token = tokenStore.read() ?? devJWT else { route = .signedOut; return }
        api = makeAPI(token)
        do { routeFor(try await api.me()) } catch { handle(error); if route == .loading { route = .signedOut } }
    }

    func signIn(identityToken: String) async throws {
        let (token, user) = try await api.signIn(identityToken)
        try tokenStore.write(token)
        api = makeAPI(token)
        routeFor(user)
    }

    func didEnroll(_ user: User) { routeFor(user) }

    func signOut() { tokenStore.clear(); user = nil; api = makeAPI(nil); route = .signedOut }

    /// Central error policy: UNAUTHENTICATED signs out; everything else is surfaced.
    func handle(_ error: Error) {
        if case APIError.unauthenticated = error { signOut(); return }
        lastError = (error as? APIError)?.userMessage ?? error.localizedDescription
    }

    private func routeFor(_ user: User) { self.user = user; route = user.hasVoice ? .main : .enroll }
}
```

```swift
import AVFoundation

/// Struct-of-closures so ViewModels can be tested without AVFoundation.
struct Recording {
    var requestPermission: @MainActor () async -> AudioRecorder.Permission
    var start: @MainActor () throws -> Void
    var stop: @MainActor () -> URL?
    var duration: @MainActor () -> TimeInterval
}

@MainActor @Observable
final class AudioRecorder {
    enum Permission { case undetermined, granted, denied }
    private(set) var isRecording = false
    private(set) var duration: TimeInterval = 0
    private var recorder: AVAudioRecorder?
    private var timer: Timer?
    private var url: URL?

    func requestPermission() async -> Permission {
        await AVAudioApplication.requestRecordPermission() ? .granted : .denied
    }

    func start() throws {
        let session = AVAudioSession.sharedInstance()
        try session.setCategory(.playAndRecord, mode: .default, options: [.defaultToSpeaker])
        try session.setActive(true)
        let file = FileManager.default.temporaryDirectory.appending(path: "recording_\(Int(Date().timeIntervalSince1970)).m4a")
        let settings: [String: Any] = [AVFormatIDKey: Int(kAudioFormatMPEG4AAC), AVSampleRateKey: 44_100.0, AVNumberOfChannelsKey: 1, AVEncoderAudioQualityKey: AVAudioQuality.high.rawValue]
        recorder = try AVAudioRecorder(url: file, settings: settings)
        recorder?.record()
        url = file; isRecording = true; duration = 0
        timer = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in Task { @MainActor in self?.duration += 0.1 } }
    }

    func stop() -> URL? {
        recorder?.stop(); timer?.invalidate(); timer = nil; isRecording = false
        return url
    }

    var asRecording: Recording {
        Recording(requestPermission: { await self.requestPermission() }, start: { try self.start() }, stop: { self.stop() }, duration: { self.duration })
    }
}
```

```swift
@MainActor @Observable
final class EnrollVoiceViewModel {
    enum Phase: Equatable { case idle, recording, review(URL), uploading, done(User), failed(String), permissionDenied }
    static let minimumSeconds: TimeInterval = 8
    static let referenceText = """
    I am speaking in my own voice so this app can learn how I sound. Some days are harder than others, and that is okay. \
    I can notice a difficult thought, take a breath, and choose a kinder way to say it to myself. \
    I am allowed to make mistakes, to rest, and to try again tomorrow.
    """

    private(set) var phase: Phase = .idle
    private let api: API
    private let recorder: Recording
    private var fileURL: URL?

    init(api: API, recorder: Recording) { self.api = api; self.recorder = recorder }

    func record() async {
        guard await recorder.requestPermission() == .granted else { phase = .permissionDenied; return }
        do { try recorder.start(); phase = .recording } catch { phase = .failed(error.localizedDescription) }
    }

    func stop() {
        let duration = recorder.duration()
        guard let url = recorder.stop() else { phase = .failed("Recording failed."); return }
        guard duration >= Self.minimumSeconds else { phase = .failed("Please read the whole paragraph (at least 8 seconds)."); return }
        fileURL = url; phase = .review(url)
    }

    func upload() async {
        guard let fileURL else { return }
        phase = .uploading
        do { phase = .done(try await api.enrollVoice(fileURL, Self.referenceText)) }
        catch { phase = .failed((error as? APIError)?.userMessage ?? error.localizedDescription) }
    }

    func retake() { fileURL = nil; phase = .idle }
}
```

`ios/ReframedThoughts/Features/Record/RecordFlowViewModel.swift`:
```swift
import Foundation
import Observation

extension SessionStatus {
    var progressLabel: String {
        switch self {
        case .uploaded: "Uploading…"
        case .transcribing: "Listening…"
        case .reframing: "Reframing…"
        case .synthesizing: "Finding your voice…"
        case .completed: "Done"
        case .failed: "Failed"
        }
    }
}

@MainActor @Observable
final class RecordFlowViewModel {
    enum Phase: Equatable { case idle, recording, uploading, processing(SessionStatus), done(Session), failed(String), permissionDenied }
    private(set) var phase: Phase = .idle
    private let api: API
    private let recorder: Recording
    private let onUnauthenticated: () -> Void
    private var watchTask: Task<Void, Never>?

    init(api: API, recorder: Recording, onUnauthenticated: @escaping () -> Void) {
        self.api = api; self.recorder = recorder; self.onUnauthenticated = onUnauthenticated
    }

    func record() async {
        guard await recorder.requestPermission() == .granted else { phase = .permissionDenied; return }
        do { try recorder.start(); phase = .recording } catch { phase = .failed(error.localizedDescription) }
    }

    func stopAndSubmit() async {
        guard let url = recorder.stop() else { phase = .failed("Recording failed."); return }
        phase = .uploading
        do {
            let session = try await api.createSession(url)
            await follow(session.id)
        } catch { fail(error) }
    }

    func resume(session: Session) async {
        if session.status.isTerminal { phase = session.status == .completed ? .done(session) : .failed(Self.failureMessage(session.error)); return }
        phase = .processing(session.status)
        await follow(session.id)
    }

    func reset() { watchTask?.cancel(); watchTask = nil; phase = .idle }

    private func follow(_ id: String) async {
        do {
            for try await s in api.watchSession(id) {
                switch s.status {
                case .completed: phase = .done(s); return
                case .failed: phase = .failed(Self.failureMessage(s.error)); return
                default: phase = .processing(s.status)
                }
            }
            if case .processing = phase { phase = .failed("Lost connection before the affirmation was ready. Check History.") }
        } catch { fail(error) }
    }

    private func fail(_ error: Error) {
        if case APIError.unauthenticated = error { onUnauthenticated(); return }
        phase = .failed((error as? APIError)?.userMessage ?? error.localizedDescription)
    }

    static func failureMessage(_ raw: String?) -> String { "Something went wrong while reframing. Please try again." }
}
```

```swift
@MainActor @Observable
final class AudioPlayer {
    private(set) var isPlaying = false
    private var player: AVPlayer?
    private var observer: Any?

    func play(_ url: URL) {
        try? AVAudioSession.sharedInstance().setCategory(.playback, mode: .spokenAudio)
        try? AVAudioSession.sharedInstance().setActive(true)
        let item = AVPlayerItem(url: url)
        player = AVPlayer(playerItem: item)
        observer = NotificationCenter.default.addObserver(forName: .AVPlayerItemDidPlayToEndTime, object: item, queue: .main) { [weak self] _ in Task { @MainActor in self?.isPlaying = false } }
        player?.play(); isPlaying = true
    }
    func stop() { player?.pause(); isPlaying = false }
}
```
