# Reframed Thoughts Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GraphQL backend in a Docker image on Cloudflare Containers that signs users in with Apple, enrolls a cloned voice in VoiceStudio, and turns a spoken thought into a reframed affirmation spoken back in the user's voice, streaming pipeline status over subscriptions.

**Architecture:** One Node process runs GraphQL Yoga (HTTP) and graphql-ws (WebSocket) on port 8080. All external effects go through a `Deps` object (db, pubsub, r2, voice, reframe, jwks) so resolvers and the pipeline are tested with in-memory fakes and msw. A thin Cloudflare Worker proxies every request to a singleton container.

**Tech Stack:** Node 22, TypeScript (ESM), graphql-yoga 5, @pothos/core 4, graphql-ws 6 + ws, drizzle-orm + postgres (Neon), @electric-sql/pglite (tests), jose, aws4fetch, vitest, msw 2, wrangler + @cloudflare/containers.

**Spec:** `docs/superpowers/specs/2026-10-13-reframed-thoughts-design.md`

## Global Constraints

- Node 22, ESM (`"type": "module"`), strict TypeScript.
- Every change is TDD: failing test first, then minimal code. Vitest. No network in tests (msw `onUnhandledRequest: 'error'`).
- Ponytail mode: no interfaces with one implementation beyond the `Deps` seam; no new dependency where a few lines do.
- GraphQL schema exactly as in the spec: `User`, `AuthPayload`, `SessionStatus`, `Session`, `Query { me, sessions, session }`, `Mutation { signInWithApple, enrollVoice, createSession, deleteAccount }`, `Subscription { sessionUpdated }`.
- Unauthenticated access to anything but `signInWithApple` returns a GraphQL error with `extensions.code = "UNAUTHENTICATED"`.
- `audioUrl` is a presigned R2 GET valid 1 hour, generated at resolve time, never stored.
- R2 keys: `voices/{userId}.m4a`, `recordings/{sessionId}.m4a`, `affirmations/{sessionId}.mp3`.
- Container: `max_instances: 1`, `instance_type: "basic"`, `sleepAfter: "10m"`, default port 8080. Worker uses `fetch`, never `containerFetch`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A user who has not enrolled a voice calls `createSession` → must fail with `VOICE_NOT_ENROLLED` before any upload. (Test in Task 10.)
2. A user queries or subscribes to another user's session id → `session` returns null, `sessionUpdated` errors `NOT_FOUND`. (Tests in Tasks 10 and 12.)
3. VoiceStudio or OpenAI returns a non-2xx mid-pipeline → session ends `FAILED` with `error` set, an update is published, and the process does not crash. (Test in Task 11.)
4. Container restarts mid-pipeline → sweeper resumes from the first missing stage instead of re-transcribing finished work. (Test in Task 11.)
5. An expired or wrong-audience Apple identity token → `signInWithApple` errors `INVALID_APPLE_TOKEN`, no user row created. (Test in Task 5.)

const KEYS = [
  'DATABASE_URL', 'JWT_SECRET', 'APPLE_BUNDLE_ID',
  'R2_ACCOUNT_ID', 'R2_ACCESS_KEY_ID', 'R2_SECRET_ACCESS_KEY', 'R2_BUCKET',
  'VOICESTUDIO_URL', 'VOICESTUDIO_API_KEY', 'OPENAI_API_KEY', 'OPENAI_MODEL',
] as const;

export type Env = Record<(typeof KEYS)[number], string> & { PORT: number };

export function loadEnv(source: NodeJS.ProcessEnv = process.env): Env {
  const out: Record<string, string | number> = { PORT: Number(source.PORT ?? 8080) };
  for (const k of KEYS) {
    if (!source[k]) throw new Error(`Missing env var: ${k}`);
    out[k] = source[k]!;
  }
  return out as Env;
}
```

import { SignJWT, jwtVerify } from 'jose';

export const jwtSecretFrom = (s: string) => new TextEncoder().encode(s);

export function signUserToken(userId: string, secret: Uint8Array) {
  return new SignJWT({}).setProtectedHeader({ alg: 'HS256' }).setSubject(userId).setIssuedAt().setExpirationTime('90d').sign(secret);
}

export async function verifyUserToken(token: string, secret: Uint8Array): Promise<string | null> {
  try {
    const { payload } = await jwtVerify(token, secret);
    return payload.sub ?? null;
  } catch {
    return null;
  }
}

import { SignJWT, createLocalJWKSet, exportJWK, generateKeyPair } from 'jose';

export async function makeAppleSigner(audience = 'com.example.app') {
  const { publicKey, privateKey } = await generateKeyPair('RS256');
  const jwk = { ...(await exportJWK(publicKey)), kid: 'k1', alg: 'RS256', use: 'sig' };
  const jwks = createLocalJWKSet({ keys: [jwk] });
  const sign = (claims: { sub: string; aud?: string; exp?: string }) =>
    new SignJWT({}).setProtectedHeader({ alg: 'RS256', kid: 'k1' })
      .setIssuer('https://appleid.apple.com').setAudience(claims.aud ?? audience)
      .setSubject(claims.sub).setIssuedAt().setExpirationTime(claims.exp ?? '1h').sign(privateKey);
  return { jwks, audience, sign };
}
```

import { createRemoteJWKSet, jwtVerify, type JWTVerifyGetKey } from 'jose';

export const appleJwks = (): JWTVerifyGetKey => createRemoteJWKSet(new URL('https://appleid.apple.com/auth/keys'));

export async function verifyAppleIdentityToken(token: string, opts: { jwks: JWTVerifyGetKey; audience: string }) {
  try {
    const { payload } = await jwtVerify(token, opts.jwks, { issuer: 'https://appleid.apple.com', audience: opts.audience });
    if (!payload.sub) throw new Error('no sub');
    return { sub: payload.sub };
  } catch {
    throw new Error('INVALID_APPLE_TOKEN');
  }
}

import { AwsClient } from 'aws4fetch';
import type { R2 } from '../deps.js';

export function createR2(cfg: { accountId: string; accessKeyId: string; secretAccessKey: string; bucket: string }): R2 {
  const aws = new AwsClient({ accessKeyId: cfg.accessKeyId, secretAccessKey: cfg.secretAccessKey, service: 's3', region: 'auto' });
  const url = (key: string) => `https://${cfg.accountId}.r2.cloudflarestorage.com/${cfg.bucket}/${key}`;
  const call = async (method: string, key: string, init?: RequestInit) => {
    const res = await aws.fetch(url(key), { method, ...init });
    if (!res.ok) throw new Error(`R2 ${method} ${key}: ${res.status}`);
    return res;
  };
  return {
    put: async (key, body, contentType) => { await call('PUT', key, { body, headers: { 'content-type': contentType } }); },
    get: async (key) => new Uint8Array(await (await call('GET', key)).arrayBuffer()),
    delete: async (key) => { await call('DELETE', key); },
    presignGet: async (key) => {
      const signed = await aws.sign(new Request(`${url(key)}?X-Amz-Expires=3600`, { method: 'GET' }), { aws: { signQuery: true } });
      return signed.url;
    },
  };
}

import type { VoiceStudio } from '../deps.js';

export function createVoiceStudio(cfg: { baseUrl: string; apiKey: string }): VoiceStudio {
  const call = async (method: string, path: string, init: RequestInit = {}, okStatuses: number[] = []) => {
    const res = await fetch(cfg.baseUrl + path, { ...init, method, headers: { authorization: `Bearer ${cfg.apiKey}`, ...(init.headers ?? {}) } });
    if (!res.ok && !okStatuses.includes(res.status)) throw new Error(`VoiceStudio ${method} ${path}: ${res.status}`);
    return res;
  };
  const audioForm = (field: string, audio: Uint8Array, extra: Record<string, string>) => {
    const form = new FormData();
    form.append(field, new File([audio], 'sample.m4a', { type: 'audio/mp4' }));
    for (const [k, v] of Object.entries(extra)) form.append(k, v);
    return form;
  };
  return {
    createProfile: async ({ name, audio, referenceText }) => {
      const res = await call('POST', '/profiles', { body: audioForm('ref_audio', audio, { name, ref_text: referenceText, kind: 'clone' }) });
      return (await res.json() as { id: string }).id;
    },
    deleteProfile: async (id) => { await call('DELETE', `/profiles/${id}`, {}, [404]); },
    transcribe: async (audio) => {
      const res = await call('POST', '/v1/audio/transcriptions', { body: audioForm('file', audio, { model: 'whisper-1' }) });
      return (await res.json() as { text: string }).text;
    },
    synthesize: async ({ text, voice }) => {
      const res = await call('POST', '/v1/audio/speech', {
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ model: 'tts-1', voice, input: text, response_format: 'mp3' }),
      });
      return new Uint8Array(await res.arrayBuffer());
    },
  };
}

import { sessions, users, type SessionRow, type SessionStatus } from '../db/schema.js';
import type { Deps } from '../deps.js';

const TERMINAL: SessionStatus[] = ['COMPLETED', 'FAILED'];

async function transition(deps: Deps, id: string, patch: Partial<typeof sessions.$inferInsert> & { status: SessionStatus }): Promise<SessionRow> {
  const [row] = await deps.db.update(sessions).set({ ...patch, updatedAt: new Date() }).where(eq(sessions.id, id)).returning();
  deps.pubsub.publish('session', id, row);
  return row;
}

// ponytail: in-process runner + boot sweeper; move to a Cloudflare Queue consumer if jobs get lost in practice.
export async function runPipeline(deps: Deps, sessionId: string): Promise<void> {
  const [s] = await deps.db.select().from(sessions).where(eq(sessions.id, sessionId));
  if (!s || TERMINAL.includes(s.status)) return;
  try {
    let transcript = s.transcript;
    if (!transcript) {
      await transition(deps, sessionId, { status: 'TRANSCRIBING' });
      transcript = await deps.voice.transcribe(await deps.r2.get(s.recordingKey));
    }
    let reframedText = s.reframedText;
    if (!reframedText) {
      await transition(deps, sessionId, { status: 'REFRAMING', transcript });
      reframedText = await deps.reframe(transcript);
    }
    await transition(deps, sessionId, { status: 'SYNTHESIZING', transcript, reframedText });
    const [user] = await deps.db.select().from(users).where(eq(users.id, s.userId));
    if (!user?.voiceProfileId) throw new Error('VOICE_NOT_ENROLLED');
    const mp3 = await deps.voice.synthesize({ text: reframedText, voice: user.voiceProfileId });
    const audioKey = `affirmations/${sessionId}.mp3`;
    await deps.r2.put(audioKey, mp3, 'audio/mpeg');
    await transition(deps, sessionId, { status: 'COMPLETED', audioKey });
  } catch (err) {
    await transition(deps, sessionId, { status: 'FAILED', error: err instanceof Error ? err.message : String(err) });
  }
}

export async function sweepStuckSessions(deps: Deps, olderThanMs = 120_000): Promise<string[]> {
  const cutoff = new Date(Date.now() - olderThanMs);
  const stuck = await deps.db.select({ id: sessions.id }).from(sessions)
    .where(and(notInArray(sessions.status, TERMINAL), lt(sessions.updatedAt, cutoff)));
  for (const { id } of stuck) await runPipeline(deps, id);
  return stuck.map((s) => s.id);
}

export const createPipelineStarter = (deps: Deps) => (id: string) => {
  void runPipeline(deps, id).catch((e) => console.error('pipeline crashed', id, e));
};

export async function startServer(deps: Deps, port: number) {
  const yoga = createApp(deps);
  const http = createServer(yoga);
  const wss = new WebSocketServer({ server: http, path: yoga.graphqlEndpoint });
  useServer({
    execute: (args: any) => args.rootValue.execute(args),
    subscribe: (args: any) => args.rootValue.subscribe(args),
    onSubscribe: async (ctx, _id, payload) => {
      const { schema, execute, subscribe, contextFactory, parse, validate } = yoga.getEnveloped({ ...ctx, req: ctx.extra.request, socket: ctx.extra.socket, params: payload });
      const token = (ctx.connectionParams as { token?: string } | undefined)?.token;
      const args = {
        schema, operationName: payload.operationName, document: parse(payload.query), variableValues: payload.variables,
        contextValue: { ...(await contextFactory()), ...(await contextFromToken(deps, token)) },
        rootValue: { execute, subscribe },
      };
      const errors = validate(args.schema, args.document);
      return errors.length ? errors : args;
    },
  }, wss);
  await new Promise<void>((r) => http.listen(port, r));
  const addr = http.address();
  return {
    port: typeof addr === 'object' && addr ? addr.port : port,
    close: () => new Promise<void>((r) => { wss.close(); http.close(() => r()); }),
  };
}
